# Reading List

A small web page to keep a list of books you want to read.

## How to run

Open `index.html` in a browser. There is nothing to install.

## How to use

1. Type a title, an author and a rating, then click Add.
2. Click "Mark read" on a book when you finish it.
3. Use the search box and the dropdown to find books.
4. The numbers under the form show how many books you have and how many are read.
5. "Clear all books" empties the list.
