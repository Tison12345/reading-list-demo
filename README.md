# Reading List

A small web page where I keep a list of books I want to read.

## Why I am building it
I often forget which books I wanted to read. This page gives me one place to
write them down and tick them off when I finish, so I always know what to read next.

## What it does
1. Add a book with a title and an author.
2. Show all my books in a list.
3. Tick a book when I have read it (untick it to undo).
4. Remember my books after I close the page, using the browser's local storage.

## How to run it
Open `index.html` in a web browser. There is nothing to install.

## How it is built
Plain HTML and JavaScript, styled with the [Pico CSS](https://picocss.com) stylesheet
(`css/pico.min.css`, MIT licence). No server and no frameworks.
